# 树莓派开机自启动部署

本文说明如何在树莓派 5 图形化桌面环境中开机自动启动姿态检测程序，并在小屏幕上全屏显示实时检测画面。

## 前提

- 树莓派开机后会自动进入图形化桌面。
- 项目默认放在 `/home/pi/posture-detection`。
- 项目内已经创建 `.venv` 并安装依赖。
- 使用 USB 摄像头，默认摄像头编号为 `0`。

如果项目路径不是 `/home/pi/posture-detection`，需要同步修改 `scripts/raspi/posture-detection.desktop` 中的 `Exec` 路径。

## 准备 Python 环境

在树莓派上进入项目目录：

```bash
cd /home/pi/posture-detection
```

创建并激活虚拟环境：

```bash
uv venv --python 3.11
source .venv/bin/activate
uv pip install -r requirements.txt
```

如果 OpenCV 的 pip wheel 安装失败，可以先安装系统 OpenCV，再安装其余 Python 依赖。

## 手动测试

先在终端手动运行启动脚本：

```bash
chmod +x scripts/raspi/start_posture_detection.sh
scripts/raspi/start_posture_detection.sh
```

期望结果：

- OpenCV 窗口全屏显示。
- 首次没有校准文件时，程序进入正常坐姿校准。
- 校准完成后写入 `data/calibration/default.json`。
- 再次启动时，如果校准文件有效，会跳过 8 秒启动校准。

如需强制重新校准：

```bash
scripts/raspi/start_posture_detection.sh --force-calibration
```

运行过程中按 `c` 也可以重新校准，完成后会覆盖 `data/calibration/default.json`。

## 启用桌面自启动

创建 autostart 目录：

```bash
mkdir -p ~/.config/autostart
```

复制桌面启动模板：

```bash
cp scripts/raspi/posture-detection.desktop ~/.config/autostart/posture-detection.desktop
```

确保启动脚本可执行：

```bash
chmod +x /home/pi/posture-detection/scripts/raspi/start_posture_detection.sh
```

重启树莓派：

```bash
sudo reboot
```

重启后，树莓派进入图形化桌面时会自动启动姿态检测程序。

## 查看启动日志

启动脚本会把标准输出和错误输出追加到：

```bash
/home/pi/posture-detection/logs/runtime.log
```

查看最近日志：

```bash
tail -n 100 /home/pi/posture-detection/logs/runtime.log
```

如果开机后没有出现全屏窗口，优先检查：

- `posture-detection.desktop` 里的 `Exec` 路径是否正确。
- `start_posture_detection.sh` 是否有执行权限。
- `.venv` 是否存在。
- 摄像头编号是否是 `0`。
- OpenCV 是否能在当前桌面会话中打开窗口。

## 禁用自启动

删除 autostart 文件即可：

```bash
rm ~/.config/autostart/posture-detection.desktop
```

## 校准文件

默认校准文件路径：

```bash
data/calibration/default.json
```

这份文件是运行时生成的数据，不纳入 Git。当前第一版只支持固定一个学生和一个摄像头机位，因此只有一份默认校准文件。

如果更换学生、调整摄像头位置或更换桌椅高度，建议删除旧校准文件后重新启动，或运行：

```bash
scripts/raspi/start_posture_detection.sh --force-calibration
```

也可以在窗口中按 `c` 重新校准。
